# DX_FF.h 对象接口参考（SDK 1.0.1）

公开入口为 `<DX_FF.h>`。类型字段见[数据结构参考](数据结构参考.md)，完整调用顺序见[快速开始](快速开始.md)和[Training 计算流程](Training计算流程.md)。对象不可复制；`close()` 后可再次 `open()`。

## 通用约定

`Address.channel` 为 `0..2` 且须小于打开时的 `activeChannels`；`Address.rod` 是配置中的 Rod ID（`0..255`），不是数组下标。`encoder`、`position` 为编码器整数值，须符合该杆软硬限位及禁区；后缀 `Mm` 是光学毫米，换算为 `P0 + P1 × encoder`。运动接口没有速度参数；连接时按配置的 `motor_parameters.speed_limit_raw` 为各杆设置设备原始速度值，并核对加减速度及行程限位。

`Result` 的 `code == ErrorCode::None` 表示成功，可写 `if (result)`；失败检查本次返回的 `code` 和 `message`。`ValueResult<T>` 先检查 `result`，失败时不使用 `value`。错误码含 `InvalidConfiguration`、`NotOpen`、`InvalidTarget`、`SafetyViolation`、`DeviceAlarm`、`Communication`、`Timeout`、`Busy`、`BackendFailure`；含义见[错误码与状态](错误码与状态.md)。消息可供人阅读，不宜作为程序分支。

## 只读快照

下列成员是 SDK 所持数据的常量引用，仅在驱动对象存活期间有效。后续调用或状态回调可能更新内容；需长期保存时应复制，需要最新反馈时先 `refresh()`。同一对象的操作应顺序执行；状态回调内不要重入驱动，也不要在另一线程操作时并发读取快照。

| 成员 | 内容和更新时机 |
| --- | --- |
| `m_config` | `ConfigSnapshot`：机台 ID、配置版本、原始 JSON；打开成功填充，关闭成功清空。 |
| `m_status` | `DeviceStatus`：整机状态及三个通道槽位；打开、刷新、操作结果或回调可能更新；关闭成功为 `Offline`。状态值 `Ready`、`Moving`、`Fault`、`EmergencyStopped`、`Other` 见[错误码与状态](错误码与状态.md)。 |
| `m_last_error` | 最近一次报告的 `Result`，后续调用会覆盖；排错优先使用本次返回值。 |
| `m_current_positions` | 所有启用杆的反馈 `RodPosition`；打开、刷新、操作结果或回调可能更新，关闭成功清空。仅 `valid` 为真时可使用 `encoder` 和 `opticalMm`。 |

## 连接与状态

| 方法与功能 | 输入参数 | 返回和副作用 |
| --- | --- | --- |
| `open(configPath, mode, ports = {}, activeChannels = 3)`：加载配置并连接。 | `configPath`：配置 JSON 路径；`mode`：`Simulation` 或 `Hardware`；`ports`：CH1..CH3 的串口名数组，硬件模式需提供启用通道，默认全空；`activeChannels`：从 CH1 起启用的通道数 `1..3`，默认 `3`。 | `Result`：成功表示连接及快照初始化完成；失败返回原因并清理连接。已打开返回 `Busy`。不运动。 |
| `close()`：断开后端。 | 无。 | `Result`：成功后清空配置和位置快照，状态为 `Offline`；未打开也成功。失败时不能假定已断开。 |
| `refresh()`：读取整机反馈。 | 无。 | `Result`：成功更新状态和当前位置快照；失败看 `code/message`。要求已打开，不运动。 |
| `refresh_rod(address)`：读取指定杆反馈。 | `address`：启用通道和已配置杆 ID。 | `Result`：成功表示反馈读取完成并更新快照。要求已打开，不运动。 |
| `machine_info()`：读取配置摘要。 | 无。 | `MachineInfo`：启用通道数、训练杆、杆参数、层成员和间隙规则；未打开时 `activeChannels == 0`。不访问设备。 |
| `set_status_callback(callback)`：设置状态通知。 | `callback`：接收 `const DeviceStatus&` 的函数，空函数表示取消；可在打开前调用。 | `void`：无独立错误返回，最近错误置为成功。回调中不得重入驱动。 |

## 文件与运动

`load_positions()` 仅返回数据，不保存待执行目标。调用方可修改返回的目标数组，再传给多杆接口。文件读取、文件保存、单杆运动和多杆运动均在底层安全检查；多杆接口要求**每根启用杆恰好一个目标**。单杆检查本杆与相邻杆形成的边界；多杆检查最新起点完整组合与终点完整组合，不把连续联合轨迹作为通过条件。同通道各杆尽快成组下发，不保证严格同步启动。

| 方法与功能 | 输入参数 | 返回和副作用 |
| --- | --- | --- |
| `load_positions(path)`：读取并校验位置文件。 | `path`：JSON 或兼容 CSV 文件路径；须与机台、配置版本、完整启用杆集合及安全规则匹配。 | `ValueResult<PositionSet>`：成功时 `value.targets` 为每根启用杆的 `Target`，`value.summary` 为文件摘要；失败仅检查 `result`。刷新反馈并校验文件目标，不下发运动，也不保留待执行目标。 |
| `save_positions(path, positions)`：保存指定目标集。 | `path`：输出 JSON 路径；`positions`：`PositionSet`，含每根启用杆恰好一个 `Target` 及可读 `summary`。 | `Result`：成功表示刷新、完整性与安全校验通过，写出 `FF-POS-1` 文件；失败看 `code/message`。不下发运动。 |
| `record_positions(path, summary = {})`：记录当前杆位。 | `path`：输出 JSON 路径；`summary`：可读摘要，默认空字符串。 | `Result`：成功表示刷新、就绪、反馈及安全校验通过且写入完成；失败不写新文件。要求已打开且整机 `Ready`，不运动。 |
| `move_rod(address, encoder)`：单杆移动。 | `address`：启用杆；`encoder`：目标编码器整数，须符合杆限位、禁区和邻杆边界。 | `Result`：成功表示进入到位容差并满足稳定时间；失败看 `code/message`，实际位置可能已变化。要求已打开。 |
| `send_rod(address, encoder)`：单杆下发。 | 同 `move_rod`。 | `Result`：成功只表示安全检查通过且目标下发成功，**不表示到位**；调用方用 `refresh_rod()` 观察反馈。要求已打开。 |
| `move_rods(targets)`：完整目标集多杆运动。 | `targets`：`std::vector<Target>`，每根启用杆恰好一项，`address` 不重复，`position` 为编码器目标。未重新分配的杆也须提供拟保持的位置。 | `Result`：成功表示全部目标进入容差并满足稳定时间；先刷新、检查起点与终点，再按通道成组下发和等待。失败时可能已有部分运动。要求已打开。 |
| `send_rods(targets)`：完整目标集多杆下发。 | 同 `move_rods`。 | `Result`：成功只表示校验和整组下发成功，**不表示到位**；调用方随后 `refresh()` 并核对各杆 `actual` 与目标、报警和状态。要求已打开。 |
| `stop()`：取消当前运动。 | 无。 | `Result`：成功表示停止请求已处理，被中断的阻塞运动可能返回 `Busy`；要求已打开。 |
| `emergency_stop()`：软件急停。 | 无。 | `Result`：成功表示急停请求已处理；要求已打开，不能代替硬件急停回路。 |
| `reset_faults()`：请求清除故障。 | 无。 | `Result`：成功表示请求已处理，不保证已恢复 `Ready`；随后刷新确认。要求已打开。 |

位置文件格式与旧 `velocity` 字段兼容规则见[位置文件格式](位置文件格式.md)。

## Training 计算与会话

`find_valleys(samples, settings)` 得到谷值毫米位置，再由 `assign_training(channel, candidatesMm)` 返回各杆 `Aim.encoderAim`。调用方把这些值与其他启用杆拟保持的位置合成完整目标集，直接传给 `move_rods()` 或 `send_rods()`。除 `assign_training()` 会刷新设备反馈并要求已打开，其余计算和会话方法不下发运动。

| 方法与功能 | 输入参数 | 返回和副作用 |
| --- | --- | --- |
| `assign_training(channel, candidatesMm, excludedRod = -1)`：将谷值分配给 Layer 2 杆。 | `channel`：启用通道号 `0..activeChannels-1`；`candidatesMm`：光学毫米候选位置，数量不超过可分配杆数；`excludedRod`：排除的 Rod ID `0..255`，默认 `-1` 不排除。 | `ValueResult<Assignment>`：成功时 `aims` 含目标毫米、量化毫米、`encoderAim`、当前编码器及 `assigned`；`totalEncoderTravel` 是编码器行程和。空候选返回空分配；失败不用 `value`。刷新反馈，不运动。 |
| `simulated_energy(source, positionMm, startMm, endMm)`：生成模拟能量。 | `source`：通常 `Sim1` 或 `Sim2`；其余为光学毫米采样点和扫描端点。 | `uint64_t` 能量值，无 `Result` 错误通道，不访问设备。 |
| `interpolate_energy(samples, positionMm)`：插值能量。 | `samples`：位置毫米与能量序列；`positionMm`：查询位置。 | `double` 能量；范围外取近端值，空序列为 `0`。无 `Result` 错误通道。 |
| `find_valleys(samples, settings)`：检测能量谷值。 | `samples`：扫描样本；`settings`：平滑点数、突出度比例、最小谷间距毫米及数量上限，字段默认值见[数据结构参考](数据结构参考.md)。 | `vector<double>`：按位置升序的谷值光学毫米；样本不足或未检出为空。无 `Result` 错误通道。 |
| `drag_interval(candidatesMm, movingIndex, anchorMm, scanStartMm, scanEndMm, windowWidthMm = 3.0)`：求拖动区间。 | 候选点数组、零基下标、参考位置、扫描两端及正窗口宽度；坐标单位毫米，默认宽度 `3.0`。 | `DragInterval`：仅 `valid` 为真时使用毫米边界；输入无效或无区间时 `valid=false`。 |
| `save_session(path, sessionJson)`：保存原始会话。 | 输出路径、完整 `FF-TRAIN-1` JSON 文本。 | `Result`：成功表示解析校验并写入；验证时短暂使用 `path + ".validate.tmp"`。 |
| `load_session(path)`：读取原始会话。 | 输入文件路径。 | `ValueResult<string>`：成功时 `value` 为原始 JSON，失败看 `result`。 |
| `save_training_session(path, session)`：保存单通道会话。 | 输出路径及[训练会话结构](数据结构参考.md)。 | `Result`：成功表示写入并回读校验为 `FF-TRAIN-1`；数组逐项分行，小数最多三位。 |
| `load_training_session(path)`：读取单通道会话。 | 输入 `FF-TRAIN-1` 或 `FF-TRAIN-2` 文件路径。 | `ValueResult<TrainingSession>`：旧文件返回原通道；三通道文件返回保存时选中的通道。需要全部通道时使用 `load_training_archive()`。 |
| `save_training_archive(path, archive)`：保存三通道会话。 | `path`：输出 JSON 路径；`archive`：`TrainingArchive`，含机台身份、选中通道和三个可为空的通道会话。 | `Result`：成功写出 `FF-TRAIN-2`，数组逐项分行，小数最多三位；必需正数舍入为零时失败。 |
| `load_training_archive(path)`：读取三通道会话。 | `path`：新 `FF-TRAIN-2` 或旧 `FF-TRAIN-1` 路径。 | `ValueResult<TrainingArchive>`：成功时得到三个通道槽位；旧文件只填充原通道。失败看 `result`。 |
| `version()`：查询版本。 | 无。 | `const char*`：当前为 `"1.0.1"`，不访问设备。 |

安全边界见[安全边界及部署说明](安全边界及部署说明.md)。

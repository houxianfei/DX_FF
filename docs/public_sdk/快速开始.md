# FF 应用层 SDK 1.0.1：快速开始（未正式发布）

目标环境：Windows x64、Visual Studio 2019 v142、C++17。将 `include` 加入包含目录、`lib/x64/Release` 加入库目录并链接 `ff_application.lib`；运行时把 `ff_application.dll` 和 `CppDllMightyZap_Ver2010.dll` 放在程序可搜索的目录。只需包含 `<DX_FF.h>`。

`DX_FF.h` 虽使用 `.h` 扩展名，但其接口仍为 C++17，不能由纯 C 编译器直接使用。对象接口在 `DX_FF.h`；结果码、状态和其他数据类型定义在它自动包含的 `DX_FF_Types.h`。在 Visual Studio 中可对类型按住 Ctrl 并点击，跳转到类型定义。GUI 的结构化配置编辑模块只随 GUI 编译，不在 SDK 包中。

```cpp
FF::ff_driver driver;
auto r = driver.open("ff_config.json", FF::Mode::Simulation);
if (!r) return 1;
r = driver.initialize("slot_0.json"); // 校验、规划、运动并等待到位稳定
if (!r) return 2;
auto state = driver.m_status;
auto current = driver.m_current_positions; // 编码器位置及光学毫米位置
auto targets = driver.m_target_positions;
driver.close();
```

`open` 同时加载配置并连接；失败时清理已打开资源。`initialize` 加载 Slot 0 到目标位置并执行。`load_positions(path)` 只读取、检查和提交目标；`record_positions(path)` 只在当前位置安全时写入。`plan_positions()` 与 `execute_positions()` 不接收文件。`initialize()`、`execute_positions()` 和 `move_rod()` 阻塞至到位稳定或失败；`send_positions()` 和 `send_rod()` 只负责安全校验和下发，调用方需自行刷新反馈。示例工程见 `examples/`。

# SDK 1.0.1 版本说明（未正式发布）

当前 SDK 本地版本为 1.0.1，不承诺与早期开发构建的二进制兼容性。对外交付 FF_SDK_v1.0.1.zip，解压目录同名。使用同一包的头文件、导入库和 DLL，并重新编译调用方。

## 头文件与运行依赖

仅交付 DX_FF.h（对象接口）和 DX_FF_Types.h（类型、结果码和状态），应用包含 `<DX_FF.h>`。旧固定速度宏及独立运动策略头文件已删除，速度由配置 motor_parameters.speed_limit_raw 控制。部署 ff_application.dll 与 CppDllMightyZap_Ver2010.dll；目标机需兼容的 Visual C++ x64 运行库，安装程序随 Release ZIP 提供。

## 连接与运动迁移

- 任意通道组合使用 open(config, mode, ports, ChannelSelection)；旧数量重载仍表示前 N 个通道。按 enabledChannels 遍历物理通道。
- Training 前 initialize(slot0)，检查 initialized；slot0 须覆盖全部启用杆。停止/急停/复位/断开后重新初始化。
- move_rods/send_rods 要求完整启用杆集合；send_partial_rods 仅发送列出的杆，发送成功后仍须轮询到位。validate_rods 不运动。
- load_positions 返回 PositionSet，不保留待执行目标；普通文件可缺整个通道。新写 FF-POS-2，旧格式及 CSV 继续可读，旧 velocity 字段忽略。
- TrainingArchive 新写 FF-TRAIN-3，记录启用通道及 sampleCount。加载后按当前反馈重新分配/校验；采用全部 Aim，包括 assigned=false 的避让目标。

GUI 私有配置编辑不随 SDK 交付。详细迁移和业务顺序见[应用场景指南](应用场景指南.md)、[接口参考](接口参考.md)、[Training 完整流程](Training计算流程.md)和[安全边界](安全边界及部署说明.md)。

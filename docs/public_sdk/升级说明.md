# SDK 1.0.1 版本说明（未正式发布）

当前 SDK 与 FF GUI 的本地版本均为 `1.0.1`，尚未正式对外发布。本文件不将此前开发期间使用的版本号视为已发布版本，也不承诺与那些开发构建的二进制兼容性。

交付头文件为 `DX_FF.h`（对象接口）、`DX_FF_Types.h`（数据结构、结果码和状态）与 `DX_FF_MotionPolicy.h`（固定速度宏）。应用只需包含 `<DX_FF.h>`；构建和部署时必须成套使用同一版本的头文件、`ff_application.lib` 与 `ff_application.dll`。真实硬件运行还需厂商 DLL。

本地开发构建的公开 API 已收敛：`move_rod()`、`send_rod()` 保留，新增直接接收完整目标集的 `move_rods(targets)`、`send_rods(targets)`。`load_positions(path)` 现在返回含 `targets`、`summary` 的 `ValueResult<PositionSet>`，不再保存待执行目标。移除 `initialize()`、目标设置与公开验证、`plan_positions()`、旧执行方法、计划类型和待执行目标快照。原调用方应改为 `open()` → `load_positions()` → `move_rods(loaded.value.targets)`，或直接调用单杆运动，并重新编译。旧位置文件的 `velocity` 仍可读但被忽略。

位置文件现在使用独立的 `FF-POS-1`：只保留机台信息、摘要及三个通道分组的杆目标，每根杆单独一行。`save_positions(path, positions)` 可保存指定完整目标集，`record_positions()` 保存当前反馈杆位。旧 `FF-TRAIN-1` 位置文件仍可读取，但新文件不再写 Training 字段。

结构化配置编辑属于 GUI 私有功能，不随 SDK 交付。SDK 的功能与安全边界分别见[接口参考](接口参考.md)、[数据结构参考](数据结构参考.md)和[安全边界及部署说明](安全边界及部署说明.md)。

# 数据结构参考（DX_FF_Types.h，SDK 1.0.1）

这些类型定义在 `DX_FF_Types.h`，供 `DX_FF.h` 中的 `FF::ff_driver` 使用。对象方法及生命周期见[接口参考](接口参考.md)。

## 公开数据结构

### 地址、目标与位置

| 类型 | 字段与含义 |
| --- | --- |
| `Address` | `channel` 为从零开始的通道号；`rod` 为实际 Rod ID。 |
| `Target` | `address` 指定杆，`position` 为目标编码器值，`velocity` 为期望速度。 |
| `RodPosition` | `address`、`encoder` 为最近反馈位置；`opticalMm` 是按标定换算的毫米值；仅当 `valid` 为真时可作为有效反馈使用。 |
| `TargetPosition` | `address`、`encoder`、`opticalMm`、`velocity` 表示 SDK 内待执行目标；`valid` 指示该目标能否用于规划。编辑目标或加载位置文件会更新它；单纯 `refresh()` 不会。 |

`open()` 会从当时的反馈初始化每根启用杆的待执行目标，并使用该杆配置的最大速度。`m_current_positions` 是反馈，`m_target_positions` 是待执行值；二者不会始终相等。

### 配置与状态

| 类型 | 字段与含义 |
| --- | --- |
| `ConfigSnapshot` | `machineId`、`configVersion` 标识配置；`json` 为打开时读取的原始 JSON 文本。只读快照，不是可编辑配置对象。 |
| `RodInfo` / `ChannelInfo` / `MachineInfo` | `machine_info()` 返回只读的启用通道数、训练杆 ID，以及每杆的 ID、名称、软硬限位、线性标定、最大速度和到位容差。设备未打开时 `activeChannels` 为零。 |
| `LayerInfo` / `ClearanceRuleInfo` | 每个通道的 `layerMembers` 表示杆所属层、角色及相邻杆 ID；`clearanceRules` 表示同层杆对的最小毫米间隙。同一杆可有多个层记录。 |
| `RodStatus` | `address` 标识杆；`actual`、`target` 是反馈中的实际及硬件命令目标编码器值；`positionValid`、`enabled`、`alarm` 和 `alarmCode` 分别表示反馈有效性、使能、报警及厂商报警码。`target` 不等于 SDK 的待执行目标。 |
| `ChannelStatus` | `channel` 为通道号；`connected` 为连接状态；`safe` 仅在底层安全状态为 `Safe` 时为真；`rods` 是配置杆对应的反馈；`violations` 为安全违规名称列表。 |
| `DeviceStatus` | `state` 为整机状态字符串；`channels` 固定含三个通道槽位。只有启用通道的反馈用于当前运动流程；未启用槽位不能视为已连接。 |

`violations` 可能包含 `CommunicationLost`、`PositionUnknown`、`DeviceAlarm`、`HardLimitActive`、`SoftLimitViolation`、`ForbiddenRange`、`RodInterference`、`InvalidTopology`、`StaleFeedback`、`ConfigurationInvalid`、`ExternalUnsafe`；未来未知值会显示为 `Unknown`。`safe == false` 并不单独说明是哪种原因，应同时查看违规项和本次 `Result`。

### 规划与训练

| 类型 | 字段与含义 |
| --- | --- |
| `PlanStep` | `target` 是该步杆位和速度；`safePosition` 为真表示规划的安全位步骤，为假表示目标位步骤；`reason` 是可读说明。 |
| `Plan` | `configVersion` 为生成计划所用配置版本；`steps` 是规划的顺序步骤。返回计划供预览，`execute_positions()` 会按当前状态重新规划。 |
| `Sample` | `positionMm` 为扫描光学位置，`energy` 为对应图像能量。 |
| `ValleySettings` | `smoothingPoints` 为平滑点数；`minimumProminenceFraction` 为最小突出度比例；`minimumDistanceMm` 为谷值间最小距离；`maximumCount == 0` 表示不设置数量上限。默认值依次为 `5`、`0.1`、`0.5`、`0`。 |
| `Aim` | `address` 为分配到的杆；`requestedMm` 为候选毫米位置，`quantizedMm` 为编码器量化后的毫米位置；`encoderAim` 为目标编码器值；`assigned` 表示该条是否分配给候选点。 |
| `Assignment` | `aims` 为分配结果；`totalEncoderTravel` 为各杆编码器行程之和，用于比较方案，不是毫米值。 |
| `DragInterval` | `minimumMm`、`maximumMm` 为候选点可拖动的毫米区间；仅当 `valid` 为真时使用这两个边界。 |
| `TrainingSource` / `TrainingRodState` / `TrainingSession` | 结构化训练会话记录来源、通道与训练杆、扫描范围、谷值参数、样本、候选点、分配结果、各杆状态、执行目标、机台身份、时间及完成状态。 |

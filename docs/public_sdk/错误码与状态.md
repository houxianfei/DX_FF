# 错误码与状态

`Result.code`：`None`、`InvalidConfiguration`、`NotOpen`、`InvalidTarget`、`SafetyViolation`、`DeviceAlarm`、`Communication`、`Timeout`、`Busy`、`BackendFailure`。具体原因读取 `Result.message`；最近一次操作结果可读取 `driver.m_last_error`。成功操作会将其清除为 `None`。

`DeviceStatus.state` 表示整机状态；每个 `ChannelStatus` 提供连接、安全结论和违规项；每个 `RodStatus` 提供当前与目标编码器位置、反馈有效性、使能和报警码。`driver.m_status` 是最近快照；需要最新反馈先调用 `driver.refresh()`。回调收到的状态已写入 `m_status`，回调内不得重入同一对象。

公开状态字符串为 `Offline`、`Ready`、`Moving`、`Fault`、`EmergencyStopped` 和 `Other`。底层 `Initializing`、`Degraded` 当前都映射为 `Other`；详细状态与字段解释见[接口参考](接口参考.md)。

`open` 失败不会保留已连接的通道。运动过程发生报警、通信错误或到位超时会返回失败；调用方应读取状态并处理故障。`stop` 和 `emergency_stop` 是软件操作。

运动等待期间调用 `stop()` 或 `emergency_stop()` 可取消等待；被中断的运动返回 `Busy`，错误信息为 `Motion stopped`。除停止操作外，同一 `ff_driver` 对象的成员函数应顺序调用；读取快照时也应避免另一线程同时刷新或关闭对象。

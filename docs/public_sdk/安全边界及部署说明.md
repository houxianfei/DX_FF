# 安全边界及部署说明

SDK 目前检查当前状态、目标组合和规划中的顺序阶段；**不证明连续运动轨迹的机械安全性**。真实机台投运前需独立验证机械包络、限位、速度和硬件互锁。多杆目标在当前 MightyZap 后端按杆顺序下发，不保证硬实时同步。

`move_rod()` 刷新本杆及直接邻杆，检查本杆限位、禁区与邻杆间隙；直接单杆运动不会先移动到安全位。其他杆的异常不会放宽本杆与邻杆的安全边界。`m_current_positions` 是最近反馈快照，读取它不会触发 I/O；运动或记录前底层会重新检查。SDK 的目标集不是硬件实际位置。

软件急停不能替代硬件急停回路。Simulation 后端立即更新位置，不模拟真实通信延迟、碰撞或机械动力学。

交付 `ff_application.dll`、`ff_application.lib`、对象头文件 `DX_FF.h` 和数据结构头文件 `DX_FF_Types.h`。真实硬件运行依赖 `CppDllMightyZap_Ver2010.dll`；该厂商文件的再分发须遵守其许可。DLL 与调用方均使用 Windows x64、VS2019 v142、兼容的 C++ 运行库。

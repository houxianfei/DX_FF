# 位置文件格式

规范写入格式为 `FF-TRAIN-1` JSON，使用其中的 `machine_id`、`config_version`、`occlusion_summary` 和 `execution_targets`。每个目标包含从 0 开始的 `channel`、`rod`、编码器 `position` 和 `velocity`。`record_positions()` 写入此格式；Training 会话也可作为位置文件读取。

旧 `slot_N.csv` 只读兼容：首行表头，后续每行为 `channel,rod,position,velocity`。CSV 没有机台身份字段，因此加载时绑定当前机台和配置版本；迁移时应重新记录为 JSON。

`load_positions(path)` 不运动，但必须覆盖所有启用 Channel 的全部配置杆，每杆恰好出现一次；还要核对机台、配置版本、限位及杆间安全规则。只有全部通过才替换对象内的目标位置，失败时旧目标保持不变。`record_positions(path)` 刷新并检查所有启用杆的当前反馈和安全状态，检查失败时不写入文件。`execute_positions()` 不接收文件，使用对象中的目标并在运动前再次检查最新反馈。
